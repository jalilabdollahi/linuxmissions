# Module 11: Find and Pipelines

This module goes deep on `find` (name, type, size, time predicates and actions) and on the classic line filters (grep's option set, cut, paste, join, comm, sort, uniq, tr, sed, awk), ending in multi-stage pipelines over real system data. Modules 1, 2 and 8 introduced find, grep, `sort | uniq`, `sed s///`, cut/awk and xargs at a basic level, so each level here teaches what those didn't: `-iname`, size units and rounding, `-mtime` truncation, `-exec +`, `grep -F -f`, first-match semantics, context, key sorts, `uniq -d/-u/-i`, sed ranges and groups, awk patterns, field loops and arrays. How I handled overlaps: module 22 (data processing) reuses join/comm/paste/uniq on business CSV datasets with headers and messy keys, while this module teaches them on Unix-format system data. Module 13 is the home for what nginx, auth and syslog lines mean, so this module avoids those logs: uniq uses a DNS query log and the capstone a postfix mail log. Module 12 owns passwd/group analysis, so this module's cut/join/awk levels use other data.

## Notes

- `-xtype`, `find -printf`, `sed -i` without a suffix and `--complement` are GNU-specific. On macOS, hints should mention `gfind`/`gsed`, or levels should avoid relying on them (level 23's data is pre-generated, so the player doesn't need `-printf`).
- Setup for level 4 sets mtimes relative to "now" and saves the expected list, so the validator doesn't drift if the player takes a while.
- No mocks are needed. Every level runs on data files generated by setup.
