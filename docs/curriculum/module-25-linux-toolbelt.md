# Linux Toolbelt

This module teaches the small, lesser-known tools that solve one awkward job well: tee, xargs -0, printf, seq, yes, nl, tac, rev, fold, fmt, expand and unexpand, shuf, split and csplit, strings, od, hexdump and xxd, base64, time, script, and driving interactive programs. Each level is a concrete job where the naive approach visibly fails. Overlap decisions:
- Module 9 owns basic `tee` and `xargs`. Here tee-append protects an audit log from truncation, and xargs-null handles hostile file names.
- Module 22's tabular-output owns report layout; printf-format here is about exact field specs for a fixed-format importer.
- Module 10's split cuts binary archives by size. Module 22 splits records by field value. Here split-by-lines keeps a header in every chunk, and csplit-pattern splits documents by content.
- The `\r` and BOM cleanup in module 22 is not repeated: od-hexdump decodes binary records, and xxd-review patches bytes.
- expect isn't in the reference image, so slug 23 is replaced with the same skill using bash `coproc` or FIFOs.

## Notes
- `strings` (level 16) comes from binutils, which is not in docker/Dockerfile. Add it, or have the hint use `grep -a` / `tr` for the ASCII part (UTF-16 still needs `strings -e l` or `iconv`).
- `col` comes from bsdextrautils and `hexdump` is from util-linux; both are already in the image. `iconv` comes from libc-bin.
- GNU-only options, so these levels are Linux-only: `tac -s`, `shuf --random-source`, `split --filter` and `--additional-suffix`, `basenc`, `base64 -w0`, `expand -i`, `unexpand --first-only`, `od --endian`, and util-linux `script -c`. macOS's `script` has different flags.
- Level 21 should use workloads with wide margins (`sleep 2`, a 2 s busy loop, `dd bs=1` for syscalls) so the classification never flips on a slow CI runner.
