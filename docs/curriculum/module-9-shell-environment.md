# Module 9: Shell Environment

This module covers the interactive shell itself: how bash turns a typed line into a command (quoting, globbing, brace expansion, command substitution, redirection, pipes) and what state a shell carries (variables, the environment, PATH, aliases, options and startup files). It is the home for startup-file order, PATH, env and printenv, aliases, history mechanics and expansion rules. How I handled overlaps: module 5 (scripting) and module 21 (shell automation) are about writing robust scripts, so command-substitution, test-brackets and here-docs here focus on expansion and quoting at the command line, and module 21's levels focus on error handling inside scripts. Pipes, tee and xargs came up in modules 2 and 8 as text tools. Here they cover how the plumbing works: stderr in pipes, PIPESTATUS, a tee "T-junction" and splitting input into arguments. Module 25 keeps `tee -a` and `xargs -0`. Module 12 uses startup files for per-user provisioning (skel, profile.d, safe rc files), module 18 for editing profile.d and alias files, module 16 for PATH hijacking and secrets in history, module 23 for PATH recovery and module 24 for `env` as one inspection step among others. `case` is replaced, because modules 5 and 21 already teach it and command lookup is missing.

## Notes

- Validators can't see the player's live shell. The game runs one persistent `bash --norc -i` with `HISTFILE=/dev/null` and history off, so each level must leave an artifact: an rc or env file that the validator loads in a clean `env -i HOME=$SANDBOX/home bash -l`/`-i`, a fixed script that the validator runs against hidden fixtures, or a run log stamped with a nonce by a provided script (levels 4, 12, 13, 14, 16).
- Level 11 can't use the player's own history because the game disables it, so it works on a supplied `.bash_history`. `date -d @N` is GNU; macOS uses `date -r N`.
- Level 17 is Linux-only (`/proc/<pid>/environ`). macOS `ps eww` is restricted by SIP.
- Level 20 needs bash ≥ 4 (globstar, nocaseglob behaviour), but macOS ships bash 3.2. Mark it Linux-only, or tell macOS players to use Homebrew bash.
- Level 22 has a `deploy` binary that just prints which copy ran, so no real deployment tool is needed.
