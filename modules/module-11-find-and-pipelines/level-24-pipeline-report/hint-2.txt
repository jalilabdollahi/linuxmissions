In awk the queue ID is $6 and the from=<...> part is $7 on the from= lines:
  $7 ~ /^from=<.*@/ { ...; from[$6] = tolower(domain) }   remember the sender domain per ID
  /status=bounced/ { bounced[$6] = 1 }                    remember which IDs bounced
  END { for (q in bounced) if (q in from) print from[q] } one line per bounced message
sub(/.*@/, "", d) and sub(/>.*/, "", d) cut the domain out of $7.
