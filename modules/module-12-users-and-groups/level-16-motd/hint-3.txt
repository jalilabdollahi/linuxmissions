- chmod -x ...                the stale notice stays in the directory but run-parts skips it
- cat > ... <<'LMEND'          writes the new script (the quoted marker stops $(...) expanding now)
- df -P / | awk 'NR == 2 ...'  the second line of df's table, fifth column: the Use% value
- chmod +x                     run-parts only runs executable files
- bin/render-motd              shows the banner as users will see it
