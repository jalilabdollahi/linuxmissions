  tail -f FILE        follows the open file (descriptor): after a rename it reads the old file forever
  tail -F FILE        follows the NAME: notices the new file and reads it from the start
  tail -n0 -F FILE    the same, but without printing the last 10 lines first
  grep -m1 PATTERN    stop after the first matching line
  timeout 60 CMD      stop CMD after 60 seconds, so nothing runs forever
In the game shell, a command ending in & runs in the background, so you can start the watcher,
then run ./trigger-deploy.sh, then `wait` for the watcher. Ctrl-C stops a foreground command.
Read more: man tail (--follow=name, --retry), man grep (-m, -o)
