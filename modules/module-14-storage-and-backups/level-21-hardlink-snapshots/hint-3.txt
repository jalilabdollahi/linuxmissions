- rsync -a site/ snapshots/day1/              the first snapshot: a complete independent copy with attributes
- ./change-day.sh                             tomorrow's edits, deletions and new files, applied to site/
- --link-dest=../day1                         relative to snapshots/day2/ (the destination): unchanged files are hard links to day1's
- ls -li                                      same inode number = stored once; edited files have different numbers
