- 1st-2nd sed    delete the three settings in the main file, the drop-ins and the Match override, then set them right after the Include line (before any Match block)
- chmod (keys)   items 4 and 5; on an already-compliant item they change nothing
- sudoers sed    the admin group keeps sudo but must type a password
- profile.d      a stale 99-umask.conf is never loaded, so remove it and write a .sh file with umask 027
- chmod 1777     the sticky bit on /tmp
- SUID loop      strip s-bits from every file not in the baseline
- HISTCONTROL    drop the old setting, add ignoreboth (ignores commands that start with a space)
- grep | xargs   find files with secret settings or AWS key ids and replace the values by a placeholder
- last find      world-writable regular files lose o+w
