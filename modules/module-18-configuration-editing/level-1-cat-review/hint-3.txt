- cat -A                 shows ^M, ^I, $ and M-BM- so you can see what is wrong (run it again to check)
- s/\r$//                removes the carriage return at the end of every line
- s/\xc2\xa0/ /g         turns each non-breaking space into a normal space, keeping "port = 8080"
- s/[[:space:]]*$//      strips trailing blanks and tabs
- sed -i                 writes the result back into app.conf
