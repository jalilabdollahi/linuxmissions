- set -a / set +a     everything assigned in between is exported to child processes
- . ./deploy.env      reads APP_HOST and APP_PORT into the shell
- '$APP_HOST $APP_PORT'  the shell-format list: only these two (also in ${APP_PORT} form) are replaced
- < ... > nginx.conf  template in, rendered file out; the template itself stays untouched
