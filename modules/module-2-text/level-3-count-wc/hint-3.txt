Type it as one block (the prompt waits until the closing brace):

{
  echo "requests=$(wc -l < access.log)"
  echo "unique_ips=$(awk '{print $1}' access.log | sort -u | wc -l)"
  echo "bytes=$(awk '{sum += $10} END {print sum}' access.log)"
} > report.txt

  line 1: wc -l counts lines, one per request
  line 2: awk prints each IP, sort -u keeps one of each, wc -l counts them
  line 3: awk adds field 10 (the size after the status code) and prints the total
  { ... } > report.txt sends all three lines into the file
