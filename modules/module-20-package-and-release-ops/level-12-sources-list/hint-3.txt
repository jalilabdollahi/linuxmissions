- sed           fixes the suite name in ubuntu.sources (the Ubuntu archive lives in ubuntu.sources)
- : > sources.list   empties the old file, whose entries repeat ubuntu.sources
- printf > vendor.sources   the vendor entry in deb822 form (URI, suite, component, key from vendor.list)
- rm vendor.list    the old one-line entry would be a duplicate
