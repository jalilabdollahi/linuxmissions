  grep -n '^set default' sysroot/boot/grub/grub.cfg     the pinned default
  grep -n 'menuentry\|submenu' sysroot/boot/grub/grub.cfg    every entry, with line numbers and indentation
In "A>B", A is the index of a top-level item and B an index inside that item's submenu.
Entries inside "submenu ... { }" are indented. The kernel version is in the entry's
linux line (the vmlinuz file name). See the GRUB manual, section "default".
