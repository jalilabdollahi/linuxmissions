The drop-in is a file ending in .conf with a [Service] section. ExecStart= can be given
several times for a oneshot unit and the values add up, so to replace the command you
first assign it an empty value (ExecStart=) and then the new command on the next line.
Wait-online helpers have an option that limits the wait (see their man page: --any or --timeout=).
