  dpkg-deb -c PKG.deb                      list a package's files;  dpkg-deb -x PKG.deb DIR  unpack it
  rescue/ld.so --library-path DIR PROGRAM  run a program with libraries taken from DIR first
A library file is usually named libX.so.N.M.P with a link libX.so.N (its SONAME) next to
it: the loader looks for the SONAME. The package here ships only the versioned file, so create the
link yourself (ln -s) in the toolkit directory. Use an absolute --library-path.
