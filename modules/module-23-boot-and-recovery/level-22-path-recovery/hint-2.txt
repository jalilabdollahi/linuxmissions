bash reads ~/.bash_profile; only if it does not exist ~/.bash_login; only if that does not exist ~/.profile.
/etc/environment is not a shell script: there are no variables in it, so $PATH stays the literal text "$PATH".
A trailing or doubled colon in PATH is an empty component, which means the current directory. Every
directory should be added once. See man bash, section INVOCATION.
