bin/usermod -s SHELL ops and bin/chage -E -1 ops (no expiry) work on sysroot. With StrictModes sshd
refuses keys when the file, .ssh or the home directory is writable by group or others, and wants
.ssh and authorized_keys private. A file /etc/nologin blocks every login except root. See man sshd_config.
