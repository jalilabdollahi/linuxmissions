  unexpand -t 8 --first-only   turns leading runs of 8 spaces into tabs (tab stops every 8)
  grep -nP '^\t' FILE          list lines that start with a tab; cat -A shows tabs as ^I
Running unexpand over the whole file also converts the variable continuation
lines and indented comments. So split the job: let awk find the recipe lines (a
flag that is set after a "target:" line and cleared by a blank line or an
unindented line) and print their line numbers, then send only those lines through
unexpand. Write the result to a new file and mv it over Makefile.
More: man unexpand, man awk
