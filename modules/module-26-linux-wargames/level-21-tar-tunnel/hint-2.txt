`tar` can write an archive to stdout and read one from stdin (`-f -`), and it records modes, mtimes, symlinks and hard links. `base64` makes binary printable with 76-character lines, exactly what the relay accepts. `split -b N -d` cuts a file into numbered parts; put the part number inside each message (a first line) because file names in bravo/inbox/ are random. To rebuild: sort the messages by that number, remove the header, concatenate, `base64 -d`, then `tar -x`. As a normal user tar applies your umask to permissions unless you give it `-p`. `./relay send FILE` sends one message.
