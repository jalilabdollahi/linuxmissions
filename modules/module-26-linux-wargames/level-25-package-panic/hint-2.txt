In awk, `-v RS=` (empty record separator) makes each blank-line separated paragraph one record; with `-F'\n'` each line is a field, so `$i ~ /^Status: /` picks fields (anchoring avoids matching prose inside descriptions). Status has three words: `want flag state`. For versions use `dpkg --compare-versions A OP B` (OP: lt le eq ge gt, or << <= = >= >>); it handles epochs (`1:`), `~` and `1.2.10 > 1.2.9`. A dependency order is what `tsort` computes from `before after` pairs. `man dpkg` and `man deb-version` explain the rules.
