`man grub-mkconfig` / the GRUB manual explain `set default`: `N` is a top-level index counted from 0 (a submenu counts as one item), `N>M` selects entry M inside submenu N. Compare each entry's `linux`, `initrd` and `root=UUID=` / `search ... --set=root UUID` with `ls sysroot/boot` and `blkid.txt` (the comments in fstab say which device each old UUID belonged to). An entry whose initrd lacks the driver for the root disk (the sim tells which one) is as unusable as one with a missing file. For fstab, a device that no longer exists needs `nofail` (see `man fstab`). `systemctl get-default`-style reasoning applies to etc/systemd/system/default.target: read the link with `readlink`.
