  pgrep -f heavy.sh           PID of the process whose command line has heavy.sh
  ps -o pid,ni,args -p PID    show its niceness (NI column)
  renice VALUE -p PID         set the niceness of a running process
Niceness goes from -20 (greediest) to 19 (nicest); the default is 0. A normal
user may only raise it. nice -n VALUE CMD is for starting a NEW process.
