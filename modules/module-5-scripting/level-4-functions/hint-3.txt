Type this at the prompt. It replaces deploy.sh with the refactored script:

cat > deploy.sh <<'EOF'
#!/bin/bash
# deploy.sh - ship every service from build/ to releases/

deploy_service() {
  local name="$1"
  echo "==> Deploying $name"
  cp "build/$name.tar" "releases/$name.tar"
  echo "$name ready"
}

deploy_service api
deploy_service web
deploy_service worker
EOF

- deploy_service() { ... }   defines the function once, before it is used
- local name="$1"            the function's first argument, visible only inside the function
- the three lines inside     the old block, with the service name replaced by $name
- deploy_service api ...     one call per service

Check it: bash deploy.sh && ls releases
