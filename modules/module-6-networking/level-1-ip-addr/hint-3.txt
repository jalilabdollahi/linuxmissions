Type this at the prompt:

awk '$1 == "inet" { split($2, a, "/"); print $NF, a[1] }' ip_addr.txt > interfaces.txt

- $1 == "inet"          only IPv4 address lines (inet6 does not match the whole word)
- split($2, a, "/")     "10.20.4.17/24" -> a[1] = "10.20.4.17"
- print $NF, a[1]       the last field is the interface label (eno1, eno1.120, ...), then the address
- > interfaces.txt      save the result
