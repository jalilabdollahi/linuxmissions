The five fields are: minute (0-59)  hour (0-23)  day-of-month (1-31)  month (1-12)  day-of-week (0-7, 0 and 7 = Sunday).
  *      every value          1-5    a range (Mon-Fri)      mon-fri   names work for days and months
  */15   every 15th value     1,3,5  a list
The command must be an absolute path, because cron starts jobs in your home directory
with almost no environment variables.
Add a line to the end of the file with `edit crontab.txt`, or with `echo "..." >> crontab.txt`
(>> appends; > would wipe the existing jobs). Inside double quotes the shell expands
$SANDBOX to the real path before writing it into the file.
Read more: man 5 crontab
