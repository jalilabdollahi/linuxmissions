Try some inputs yourself and watch both the messages and the exit status:
  DEPLOY_ENV="prod eu 1" RELEASE=1.2.3 ./guard.sh; echo "exit $?"
  DEPLOY_ENV= RELEASE=1.2.3 ./guard.sh; echo "exit $?"
  DEPLOY_ENV=prod-eu-1 RELEASE=1.2.3-rc1 ./guard.sh; echo "exit $?"
  DEPLOY_ENV=staging RELEASE=v1.4.0 ./guard.sh; echo "exit $?"

`[` is an ordinary command: the shell splits and globs `$DEPLOY_ENV` BEFORE
`[` sees it. What does `[` receive when the value is empty, or has spaces?
When `[` cannot make sense of its arguments it prints an error and returns 2.
How does an `if [ ... ]; then stop; fi` treat a 2?

Then compare each check with RULES.txt: is `prod-*` strict enough? Is
[0-9]*.[0-9]*.[0-9]* really "digits dot digits dot digits"?
